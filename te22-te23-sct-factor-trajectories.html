New exploratory VaSSTra analysis · units 1–10

SCT-oriented activity trajectories

This explorer describes how students work, using three transparent composites—mastery versus withdrawal, distributed work, and continuity—plus idle time in lessons, hard-exercise attempts, and pace relative to the class. The SCT survey is used for validation, not as an input to the trajectories.

This is an exploratory analysis. The six inputs are standardized within unit × class. States are fitted to active student-units; a zero state means no activity in that unit.

Inputs

State profiles

Values are mean standardized scores among active student-units. Higher is more of the named behavior.

Sequence index

One row per student; units run left to right. The selected model and state count change the state colors and trajectory summaries.

Trajectory summaries

Source: consented TE22/TE23 logs and SCT-linked student records. The page contains aggregate results only. Students excluded by the established inactive rule are not included.
